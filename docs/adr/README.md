# Registro de decisiones de arquitectura (ADR)

Cada decisión con varias alternativas válidas se registra aquí con el formato
de Michael Nygard: contexto, decisión, alternativas y consecuencias. Una ADR
no se edita una vez aceptada: si la decisión cambia, se escribe otra que la
sustituye y se marca la antigua como `sustituida por ADR-NNNN`.
